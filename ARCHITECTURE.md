# M-Core P versus NP research architecture

Scientific status: research scaffold, not a proof of P≠NP.

Pipeline: Official statement → Specification → computation model → languages/classes → reductions → Signature → asymptotic boundary atlas → ProofDAG → AttackDAG → Bridges → Adapters → Frontier → Endpoint → audit → reproduction.

Canonical logical obstruction: O_PNP := SAT∈P; target false after a certified Cook–Levin/specification adapter. Quantitative research observable κ_PNP := liminf log(T_SAT(n))/log n only after a deterministic model, worst-case measure and optimal-runtime quantifiers are formalized. κ is not itself the official endpoint.

Boundary protocol is discrete/asymptotic: finite n → pre-asymptotic → n→∞ → asymptotic classification. Test subsequences, liminf/limsup, nonuniformity, oscillation and compactification n↦1/n. Never assert literal 1/0 or 0/0 unless a derived real-valued quotient justifies it.

Attack loop includes relativization, natural proofs, algebrization, average/worst-case mismatch, quantifier reversal, hidden optimization and circular lower-bound assumptions.

Cross-problem relations require explicit certified adapters.
